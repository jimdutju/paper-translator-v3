## 观察

评价遵守用户指定的翻译边界。图注/标签、页眉页脚及其他指定保留区出现英文，本身不算漏译；必须先确定该区域要求翻译，才能认定漏译。本次修改保留原有区域规则，没有为了“消灭英文”改动它们。

## 找到并修复的实际错误

### 1. 旧缓存悄悄丢失数学变量

新增检查在 Bollerslev 的两段既有缓存中发现数学占位符缺失：

- PDF p8：源段有 `ε_t²` 对应的占位符，旧中文没有。
- PDF p9：源段有 `1/T` 对应的占位符，旧中文没有。

现在读取缓存时先比较占位符的编号和出现次数；有缺失或重复的段落单独重译。两段已经重译并通过数学占位符核对，其余段落继续使用缓存。

这只能保证转写之后的公式没有在文字翻译中被删除或改写。比如 p9 中 `1/T` 与“渐近方差”的中文语法关系仍欠自然；占位符完整不能证明语义准确，更不能证明视觉模型没有抄错原公式。

### 2. 逐行定义被重新合成段落

对于多行 `$数学表达式$ = 英文说明`，保留独立的正文行并禁止跨行残句拼接；不把它们当成纯数学公式编译。纯公式多行仍走原有公式排版路径。可用 `TR_DEFINITION_LINES=0` 关闭作回归比较。

### 3. 构建成功状态不可靠

旧批量入口会在有告警时返回成功，并仅凭 PDF 文件存在就跳过。现在：

- 每篇产物有带 SHA-256 的结构检查记录。
- 有告警或文字压图时退出码为非零，汇总显示 `REVIEW`。
- 只有结构检查通过且文件哈希匹配，才自动跳过。
- 新增空白页、残留占位符和可识别 LaTeX 源码检测。

### 4. 本机路径与版本耦合

- 权重、LaTeX、字体和 API 通过环境变量/本地配置设置。
- v3 使用自己的 `.cache/`，不再向冻结的 v2 缓存写入。
- 新文件自动提取可用的文字层几何；无可用层时走原有路径，`TR_GEOMETRY=0` 可关闭。
- 修复 Windows 输入/输出不在同一磁盘时 `relpath` 抛错的问题。

## 复现方式

原论文和完整译文没有随仓库分发。请自行准备具有相同文件名的 PDF，然后运行：

```powershell
python translate.py 04_bollerslev1986.pdf 06_engle2002.pdf 15_ledoitwolf2004.pdf -j 2 -o output
python -m unittest discover -s tests -v
```

比较工具使用相同后端：

```text
pdf2zh 04_bollerslev1986.pdf -p 1 -s deepseek -t 2 -o comparison
pdf2zh 15_ledoitwolf2004.pdf -p 4 -s deepseek -t 2 -o comparison
pdf2zh 06_engle2002.pdf -s deepseek -t 3 -o comparison
```

pdf2zh 的选页模式仍可能保留其余未翻译页面，不能把整个输出文件的页数当作已翻译页数。

## 仍需解决

- 没有独立的全文语义标注或跨工具盲评。
- VLM 漏段、识错字或读错公式仍可能通过结构检查。
- 表内和图中文字保留原图；指定保留英文的区域不计为漏译。若另有需要，将图表内部文字翻成中文属于额外能力。
- 页间不能自由回填所有内容，中文较短的页面仍可能留下较大空白。
- 复杂跨栏表格、标题角色和个别公式编号仍需人工复核。
- 尚未在干净的新机器上完成从零安装和冷缓存全流程验证。
